Interaction design

4Key map: Arrows = speaker, Shifts alone = flags, Space = listener, double-click = claimworth a look
PickedYour spec named three different schemes across the recording (Fn + ArrowRight, then left vs right Shift, then spacebar for both). Resolved: ArrowLeft/ArrowRight set who is speaking, left/right Shift pressed alone flag for that side, Space flags for the listener, double-click flags the exact claim, F fact-checks, comma opens settings.
AlternativeFn-based mapping (impossible: browsers cannot see the Fn key) or spacebar-for-both (needs reliable turn-taking detection, which you yourself called not straightforward).
Cost if wrongA remap is a one-file change in keymap.ts. Try the current scheme in a real conversation first.

Cost if wrongCopy tweak, minutes.

Architecture

6No live transcription in v0.1, engine interface for v0.2fine
PickedNo whisper binary was installed and subagents must not install software. v0.1 ships a replay demo engine plus real audio recording; live engines plug into shared/engine.ts in v0.2.
AlternativeBlock the build on a whisper install, or ship a half-tested streaming pipeline.
Cost if wrongDemo-only realtime for now; the v0.2 handover doc carries the engine decision (see open threads).
7Sessions persist as human-readable markdown filesfine
PickedOne .md per session as the source of truth (your markdown-over-databases standing preference), round-trip guarded by a tested parser.
AlternativeSQLite or JSON store: faster to query, opaque to read and grep.
Cost if wrongFormat migration later; two known rare escaping edge cases are queued for a v0.2 hardening pass.
8@types/node allowed as a dev dependencyfine
PickedPlan amended so the server code gets a real type net; the original whitelist made its own type-check requirement impossible.
AlternativeLeave server .mjs unchecked by the compiler.
Cost if wrongOne dev-only package, zero runtime surface.
9Markdown format extended beyond the plan samplefine
PickedSession-id header and a few tokens (interim, eta, summary ids) added so every model field survives save and reload; the plan sample was illustrative, the type definitions normative.
AlternativeFollow the sample literally and silently lose fields on round-trip.
Cost if wrongA few extra tokens per file; the parser ignores unknown lines anyway.
10Persistence trio: no autosave on speaker switch, collision-safe session ids, contract-tested duplicate parserfine
PickedSpeaker switching marks state dirty without a disk write; same-second session creation retries instead of clobbering; the server's hand-rolled markdown code is pinned to the shared TypeScript module by contract tests.
AlternativeSave on every keystroke-level event; trust timestamps to be unique; trust two parsers to stay in sync by discipline.
Cost if wrongMinor churn; the contract test already caught one real divergence (newline escaping) during review.
11Seek contract is a callback prop, not a DOM CustomEventfine
PickedSvelte 5 deprecates the event-dispatcher idiom; onseek(t) callback props are the current convention. Plan amended to match.
AlternativeBubbling CustomEvents as the plan originally said.
Cost if wrongMechanical swap in one component.
12HTTP Range support required on audio, reversing the plan's own waiverfine
PickedEmpirical test showed clicking 85% across the timeline landed at 0.24 seconds without Range support; the plan's "not required" line was a defect. After the fix the same click landed with a 0.00s delta.
AlternativeClient-side workarounds around broken seeking.
Cost if wrongAbout 30 well-tested server lines. None in practice.
13Autosave got a 10-second max-wait ceiling mid-buildfine
PickedContinuous transcript ticks starved the 2s debounce so demo sessions never saved until the end; fixed immediately rather than deferring a data-persistence bug.
AlternativeDefer to the final review pile.
Cost if wrongSlightly chattier disk writes.
14Replay engine is demo-only, live sessions record without a transcriptfine
PickedReview caught live sessions silently running the scripted demo transcript over your real recording. Ruled: replay belongs to the demo button only; a live session in v0.1 records audio, takes flags and notes, and honestly shows no machine transcript.
AlternativeKeep the scripted transcript playing during live conversations (misleading) or block live mode entirely.
Cost if wrongNone; this is the honest v0.1 shape until live transcription lands.

AI behavior

15AI claim extraction never touches double-clicked flagsfine
PickedA double-click is your exact selection; review found the LLM was overwriting it with a guess from the wrong segment. Only key-created flags (which have no span yet) go through claim extraction.
AlternativeLet the model refine manual selections too.
Cost if wrongA gating flag; could later become a setting.
16Ollama base URL overridable via env var, default stays localfine
PickedTALKWEAVE_OLLAMA_BASE_URL exists so tests can stub the model server; without it the required end-to-end tests were impossible. Default remains 127.0.0.1:11434.
AlternativeHardcode the URL and skip stub-based end-to-end testing.
Cost if wrongIn principle the env var could point LLM traffic elsewhere; acceptable on a single-user local tool, and nothing sets it by default.
17Fact-checks persist at dispatch; the "keep" pin is session-ephemeralworth a look

Cost if wrongReopening an old session shows its fact-checks unpinned. Queued as a v0.1.1 decision in the polish handover.
21Final fix wave kept to three items, save-failure chip deferredfine
